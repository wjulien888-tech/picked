# 验证记录与边界

以下为 2026 年 11 月 4 日至 5 日开发过程中的功能检查，不是学习效果或生产环境可靠性研究。

## 已做的检查

- 旧版对话、笔记向 IndexedDB 版本迁移。
- DeepSeek 流式问答；真实识别测试图左右红/蓝颜色，从 PDF、DOCX 读取 137 USD，从 CSV 读取二月数值 150。
- Markdown、表格、代码、公式、Mermaid 与隔离 HTML 预览。
- 图片、WAV、MP4 记录、播放及随消息收入笔记；测试音频 0.5 秒、视频 1 秒。
- 选中摘录、直接编辑、来源保留、多笔记本、移动、收藏、标签、搜索和类型筛选。
- 停止流式生成后保留已收到的内容。
- 完整 JSON 备份中 7 个测试附件与原文件逐字节相同；在独立浏览器存储环境恢复成功。
- 离线 HTML 包含媒体原文件，避免依赖临时 blob URL。
- 取消历史对照码 HISTORY-ALPHA、选择笔记 NOTE-BETA 后，实际请求不含被排除历史，模型返回 NOTE-BETA。
- AI 整理不自动改动原笔记；采纳保存版本并进入待验证；恢复旧版本成功；原文变化后阻止旧建议直接覆盖。
- 1200×600 桌面、390×600 窄屏的实际滚动；390 像素审阅弹窗；320 像素宽布局检查。
- 设备 Key 记住、刷新恢复、取消保存及清除；使用测试值完成界面验证，完整备份不含该测试值。

## 仓库内自动检查

```bash
npm test
npm run check
```

检查覆盖上下文选择、当前提问保留、知识状态传递、备份合并的引用重映射，以及设备 Key 的恢复、地址隔离、清除和存储失败路径。测试不需要真实 API Key，也不调用模型服务。

## 尚未覆盖
