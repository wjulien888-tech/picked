# 架构与数据边界

## 组成

`dist/index.html` 和 `style.css` 提供界面；`app.js` 负责会话、媒体、本地存储、模型请求与导出；`harness.js` 扩展材料选择、请求快照、知识状态、版本与 AI 整理审阅。

应用目前以经典脚本共享状态和函数。它适合快速迭代，模块边界与大型场景的维护性仍有改进空间。模型请求直接从浏览器发送，不经过 `serve.py`；该服务器只提供静态文件。

## 本地存储

| 数据 | 存放位置 | 进入完整备份 |
| --- | --- | --- |
| 会话、草稿、笔记、状态、版本、审阅建议 | IndexedDB 工作区记录 | 是 |
| 图片、音视频及其他本地原文件 | IndexedDB 文件存储 | 是 |
| 本次页面的 API Key | 页面内存 | 否 |
| 用户选择记住的 API Key | 单独的 localStorage 记录 | 否 |

同一来源的浏览器脚本可以读取 localStorage；设备记住功能不等于加密保管。清除浏览器网站数据会删除资料与设备保存的 Key。

完整备份导入采用合并方式，并重映射会话、笔记和附件标识。材料排除项、所选笔记、版本附件和请求记录的附件引用应随之重映射。跨窗口修改通过版本检查避免静默覆盖，冲突时提示备份和刷新。

## 请求组装

1. 读取当前会话的材料选择。
2. 排除未选中的历史和附件，保留当前提问。
3. 加入用户选中的笔记正文与知识状态。
4. 将支持的图像转成视觉输入；将文档提取文字加入对应消息。
5. 将系统设置、模型及消息组装成兼容接口请求。
6. 保存发送时的文本快照、附件引用及请求 SHA-256 摘要。Key 只放在认证请求头中。

保存的记录用说明代替图片的 Base64 数据，并保留原附件引用。摘要用于核对请求内容，不是外部可信的审计证明或防篡改签名。

## AI 整理与采纳

整理请求使用用户选择的单条笔记正文、原始摘录及已提取附件文字，返回独立草稿。用户可以比较前后内容并编辑草稿。采纳前检查原笔记是否已变化；发生变化时，允许另存建议，阻止旧草稿直接覆盖。

用户采纳后保存版本，并将内容置于“待验证”。知识状态的最终确认需要用户操作。

## 媒体与预览

Markdown 经清理后渲染。远程 Markdown 图片需要用户点击加载。HTML/SVG 预览放在隔离 iframe 中，限制外部网络访问；Mermaid 使用严格模式。

音视频和一般文件保留原文件；当前模型接口不支持的模态不会伪装成已被理解。离线 HTML 可嵌入本地媒体，远程链接仍依赖网络。

## 当前限制

没有服务端凭据保管、云端资料同步、多人权限系统、完整任务执行器或主动工具调用循环。超大数据集、大规模多窗口并发及所有浏览器和媒体编码尚未完成验收。
